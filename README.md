# Recorrido Virtual 3D: Íconos de Videojuegos

Aplicación web interactiva desarrollada en **Unity (6.3 URP - Universal Render Pipeline)** que presenta un recorrido virtual en 3D enfocado en personajes e íconos emblemáticos de la historia de los videojuegos.

## 🚀 Enlace a la Aplicación
* **Versión Jugable (GitHub Pages):** [https://sounddresweb.github.io/VirtualTour_GameIcons/](https://sounddresweb.github.io/VirtualTour_GameIcons/)[cite: 9]

---

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Motor de Videojuegos:** Unity 6.3 (URP - Universal Render Pipeline).
* **Compilación:** WebGL.
* **Diseño Web y HUD:** HTML5, CSS3 personalizado (con diseño adaptativo y capa de advertencia para dispositivos móviles).
* **Control de Versiones:** Git y GitHub Pages.

---

## 🕹️ Instrucciones de Uso
1. Haz clic en el enlace de la versión jugable para abrir la aplicación en tu navegador web.
2. *Recomendación:* Se aconseja ingresar desde un computador de escritorio o portátil para disfrutar de la experiencia visual y los controles óptimos. Si ingresas desde un móvil, verás un aviso informativo que te permitirá continuar.
3. Utiliza los controles de navegación en pantalla y del teclado para moverte libremente por el entorno virtual e interactuar con los elementos expuestos.
4. Haz clic en el botón de **Pantalla Completa** ubicado en la barra inferior del contenedor para una experiencia inmersiva.

---

## 👥 Créditos de Modelos 3D y Activos
Los modelos 3D y elementos visuales presentados en el recorrido corresponden a los siguientes personajes icónicos:
* **Kratos** (*God of War*)
* **Master Chief** (*Halo*)
* **Marcus Fenix** (*Gears of War*)
